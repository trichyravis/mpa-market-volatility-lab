# Market Prices & Volatility Lab — The Mountain Path Academy
Historical prices for Indian and global indices, commodities (gold, silver, crude), currencies, crypto and any NSE/BSE/US stock,
with return statistics, volatility measures (rolling, EWMA, Parkinson, VIX) and ARCH / GARCH / GJR-GARCH / EGARCH models
(normal or Student-t errors) with forecasts and 1-day VaR. CSV and Excel downloads.

Data: Yahoo Finance via yfinance. No API key needed.
Run locally:  pip install -r requirements.txt  &&  streamlit run app.py
https://themountainpathacademy.com
